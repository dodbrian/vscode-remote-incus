# Restart the editor

Quit all windows of the editor you configured, then start it again. Runtime
arguments take effect when the application starts; **Reload Window** is not
sufficient.

The configuration applies to this editor installation. Remote-Incus opens the
file selected by the running editor, including its Insiders or portable
installation.

Until support is available, **Incus Setup** remains in the Explorer sidebar.
You can also run **Remote - Incus: Open Setup** from the Command Palette.
